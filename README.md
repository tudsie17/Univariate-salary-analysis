# Univariate-salary-analysis
Univariate statistical analysis of the gross annual salaries of 74 employees in Python: a frequency table, a histogram, an ECDF and a boxplot, central tendency, dispersion (CV, IQR), outlier detection with the 1.5×IQR rule, a robustness comparison, and inequality measures (Gini, Lorenz curve, D9/D1), with HR recommendations.
